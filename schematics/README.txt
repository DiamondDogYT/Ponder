Put your .nbt schematic files in this folder.

For each file you add, add a matching entry to manifest.json (one level up)
with at least "file" and "name". "description", "author", "tags", and "size"
are optional but make the listing much more useful.

You can delete this README once you've added real schematics — it won't be
listed since it isn't referenced in manifest.json.
